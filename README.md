# Sales-claude-skills

A Claude plugin marketplace.

## Install in Claude
1. Claude desktop -> **Customize -> Plugins -> Add marketplace**
2. Enter `RohitMakaniProfile/Sales-claude-skills`
3. Install **linkedin-unipile**, then open its Connectors tab and make sure Unipile is on.

## Plugins
| Plugin | What it does |
|---|---|
| linkedin-unipile | Post on LinkedIn and fetch all comments/replies via Unipile |

## Updating
Edit files, bump `version` in both `plugin.json` and `.claude-plugin/marketplace.json`, commit and push.
Then in Claude: **Check for updates** on the marketplace (or turn on Sync automatically).
